# 从当前原型到 ME5412 课程交付

> **路线已更新。** 本文保留早期三动作与文字方法比较方案。最新主线是十个固定语意与条件动作学习，截止日期仍为 2026-11-03。当前实施与协作以 [最新六人指南](ten-intent-learning-guide.md) 和 [GitHub 分支协作](github-collaboration.md) 为准。


建议把题目收敛为“有限医疗服务场景中的文字选择与机器人手语候选表达”。研究问题是：在同一动作目录与拒绝规则下，固定匹配、句向量和本地 LLM 如何影响选对、误拒和错误执行；机器人形态又限制了哪些动作特征。不要把题目写成任意英文到完整 ASL 的翻译系统。

课程简报允许概念、设计和仿真，不要求硬件原型；报告用 slides，简报所列截止日为 2026-11-03，展示 10–15 分钟、问答 5 分钟。本方案按你们确认的六人组织。本文日期安排是建议，不表示这些未来阶段已完成。

## 实现主线

```text
英文输入 / 短语选择
  → 公共拒绝检查 → exact / MiniLM / 本地 LLM
  → 合法候选 ID 或明确拒绝
  → 独立的候选预览门槛
  → 已验收的关节轨迹 → MuJoCo 回放与视频

公开视频 → 人工观察手型/掌向/位置/路径
  → 人工关键位姿 → 有限位的 IK → 插值 → 逐帧检查
```

语言模块输出离散编号，不输出关节角。这样可以分别发现“输入理解错”和“动作做得不像”的问题；否则一个端到端结果很难说明究竟改进了什么。当前六人任务和可直接交给各自 agent 的提示见 [接手任务卡](six-person-handoff.md)。

## 先弄懂现有机器人方法

输入是人工定义的手掌位置、方向和时间点；输出是 `positions[T,53]`，每行对应一个时刻、每列对应明确命名的关节。53 个坐标包含从动关节，不能当作 53 个独立驱动。模型固定底座，保留 12 条手指耦合关系。

`scripts/build_motions.py` 用有界最小二乘求每只手臂的关节角：同时减小手掌位置误差、旋转误差、相对上一姿态的变化，并对部分手臂与躯干几何距离不足施加惩罚。位置、旋转和距离项使用工程权重；优化收敛不自动证明动作正确或无碰撞，必须再检查整条轨迹。

关键帧之间采用 `s(u)=3u²−2u³`，`q(u)=(1−s)q₀+s q₁`。其中 `u` 是该段归一化时间，`q₀/q₁` 是相邻关键帧关节向量；段端速度为零，但不保证加速度连续。THANK_YOU 的核心段增加了手掌位置与朝向的中间目标，避免仅插值两端关节角造成指尖向上绕行。完整动作的准备和收手阶段应与手语核心段分开评价。

必须掌握的是坐标系、正逆运动学、关节限位与耦合、语义选择的拒绝边界，以及实验分母。动力学跟踪与单目动作重定向属于进阶。当前可暂缓大规模动作训练、任意句子翻译、云端部署和硬件采购。

## 展示如何组织

建议 10–12 页：场景与问题、有限范围、系统接口、机器人形态、视频观察、IK 与轨迹、三种文字选择、冻结评价、关键失败、演示、限制与后续工作。将“文字编号选对率”和“手语可理解性”分开。小数据集的零错误执行不能解释成零风险；同一公共规则的贡献也不能归给 LLM。

每位同学接手时先口头回答：我的输入输出是什么；哪些约束来自机器人、哪些来自语言；我如何证明该功能实际运行；哪类反例会使它失败；下一项实验怎样区分两种解释。回答不清楚的地方应先做最小复现实验，不能只背 agent 写出的结论。
