# P1-4 受限手指时间策略与耦合

[English](group3-finger-strategies-v2.en.md) · [任务报告](../TASK-09.md)

`pair_fingers.py` 为保存的多项式轨迹提供 synchronous、early、late 三种版本化策略。同步保留原手指路由；提前将手指路径压入前 65%，延后压入后 65%。路径中已有手指节点保留，手臂与固定坐标按精确多项式换元保持整条曲线，而非只保留采样点。

边界导数非零时，前缀/尾段不能粗暴当作静止：用同位置的短五次曲线匹配原边界 p/v/a，并在主手指相位边界回到零速度/加速度。这些附加曲线可能超调或碰撞，因此每次定时都会重算解析指标，并要求重新几何检查。

独立驱动列表排除全部耦合 child；child 的每个多项式系数都按拓扑顺序由 parent、倍率和偏移恢复。循环、重复 child、缺关节、非有限量、非法端点或端点导数耦合均拒绝。纯手指变化不会退化为零臂路径被跳过。

时间模块现在在每次定时后应用策略，再查限位/速率/加速度/jerk/耦合；独立复核器从保存曲线重新检查 0.65/0.35 相位的位置、速度和加速度，不能只信策略标签。原词核心和时序保持不变。
